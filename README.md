# 📦 Linux File Archiving and Compression Management

## 📌 Project Overview

This project demonstrates Linux file archiving and compression techniques using TAR, GZIP, BZIP2, and ZIP utilities.

The project simulates a real-world system administration task where project files must be archived, compressed, verified, transferred, and restored when required.

---

# 🎯 Objectives

- Create TAR archives
- Compress files using GZIP
- Compress files using BZIP2
- Create ZIP archives
- Verify archive contents
- Extract archived data
- Understand Linux backup and storage workflows
